# 会议到期刊内容安排（小论文 → 大论文）

> 单叙事：**确定性 / 时延预算**；VLA 是**可替换负载**。会议"刻画问题"、期刊"解决问题"，大论文把两篇合并。
> 对应关系：本文件的阶段编号统一对应《开题研究方案定稿.md》。

---

## 一、切分原则：按"问题刻画 → 问题解决"分

- **会议论文（先做先发，求快求稳）**：做"**把系统搭起来、把时延测清楚**"——平台、确定性部署、时延 / 抖动剖面。系统 / 测量类工作，**不需要算法创新**，平台搭好就能写，命中率高、审稿快。对应阶段 2–4。
- **期刊论文（后做，求完整）**：在会议平台基础上做"**时延预算驱动的自适应 chunk + 事件触发调度**"——你的核心算法 + 误差界分析 + 完整对比。对应阶段 5。
- 两篇是**同一个故事的上下集**：会议讲"平台与问题的刻画、测量"，期刊讲"在这个平台上怎么解决"。期刊引用会议（"平台部分见前期工作"），天然相关。你的内核是**确定性 / 时延预算调度**，不跟 AAC/DVAC 那批纯 ML 算法工作正面竞争，先发的系统平台还能给你的调度算法背书。

---

## 二、第一篇：会议论文（系统平台 + 时延测量）

**暂定题目**：《边缘 SoC-MCU 平台上轻量 VLA 的确定性部署与时延特性分析》

**做什么**：把系统搭起来、把时延测清楚。

具体内容：

- 异构平台架构：Orin + STM32、IPC 通信、PREEMPT_RT 实时运行时、CPU 绑核与线程分离；
- 确定性部署：量化、TensorRT、flow-matching 采样步数调节、WCET / 资源预留；
- 时延实测：推理 P50/P95/P99 时延、控制环 μs 级抖动（cyclictest）、不同优化手段的时延对比；
- 固定 chunk + 固定周期的基线闭环（HIL 硬件在环仿真）。

**贡献点**：一个可复现的**确定性**异构实时平台 + 一套时延基准数据 + 一个基线系统。

**投哪里**：国产 EI 会议为主（CCC / CAC / ICARM）。IROS / ICRA workshop 留作后期有余力时的可选扩展，不优先冲。

---

## 三、第二篇：期刊论文（调度算法 + 误差界）

**暂定题目**：《时延预算驱动的轻量 VLA 自适应 chunk 与事件触发闭环控制》

**做什么**：在会议平台上做调度算法，平台部分直接复用并引用会议论文。

具体内容：

- 时延分布建模：在线估计 d_safe（μ、σ、P99）；
- 自适应 chunk：按时延预算和任务动态度在线定长（把 chunk 从超参数变成运行时变量）；
- 事件触发重规划：状态偏差超阈值即打断重推理、MCU 兜底；
- MCU 时延补偿与 chunk 交接 blending；
- **误差有界分析（降级版）**：时序确定性保证（WCET / 资源预留）+ Lipschitz 假设下的误差界 ‖e(t)‖ ≤ L·(hT+d)+ε + 事件触发误差上界 + HIL 实验验证（不碰 Lyapunov 严格稳定性证明）；
- 完整对比与消融：固定 vs 自适应、周期 vs 事件、有无补偿。

**贡献点**：调度算法 + 误差界分析 + 完整实验。

**投哪里**：三 / 四区期刊（JSA、JRTIP、Microprocessors and Microsystems，以学校目录为准）。

## 四、大论文：两篇合并 + 补全

- **第 1 章**：绪论（背景、"慢而不确定 vs 快而确定"的矛盾、研究意义）——新写；
- **第 2 章**：相关工作（VLA 部署、action chunking、事件触发、网络控制系统）——新写；
- **第 3 章**：SmolVLA 适配与少量微调（PEFT，Full vs LoRA 作对比实验）——基础工作；
- **第 4 章**：异构实时平台与确定性部署时延测量 ——**就是会议论文**；
- **第 5 章**：时延预算驱动的自适应 chunk 与事件触发调度 ——**就是期刊论文**；
- **第 6 章**：系统综合实验（平台 + 算法完整实验合并）；
- **第 7 章**：总结与展望。

## 五、关键注意事项

1. **两篇是同一故事的上下集**：会议"刻画问题"，期刊"解决问题"，同一平台、同一时延主线，关联自然。
2. **期刊扩展比例要够**：新增算法、误差界分析、新实验占比 ≥30%，并引用会议版，避免一稿多投 / 查重问题。
3. **时间上并行**：会议投出后立刻转期刊算法，别等会议结果（期刊审稿慢）。
4. **HIL 平台只搭一次**：会议做完的平台和测量，期刊直接复用，一份工作发两篇。
5. **VLA 是可替换负载**：两篇论文的内核都是"确定性 / 时延预算调度"，若主负载卡壳即按硬 Gate 切换，论文骨架不受影响。
6. **先确认学校细则**：会议是否要求 EI 检索、期刊是否要求见刊、作者顺序要求，据此倒排投稿时间。
7. **时间弹性**：研二阶段集中解决论文工作量即可，不强绑具体月份；卡住就按 Gate 切换，不硬啃。
