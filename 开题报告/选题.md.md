# 《面向异构边缘平台的确定性 VLA 推理与时延预算驱动的实时闭环控制》

## 一、研究背景与核心问题

具身智能模型（VLA / 动作策略）推理**慢、时延大且不确定**（10–100ms，P99 不可控），而机器人伺服控制要求**快、硬实时、确定**（1kHz，μs 级抖动）。本课题研究这对 "慢而不确定的 AI 推理" 与 "快而确定的实时控制" 之间的矛盾，核心诉求是**让 AI 推理的时延可预测、可上界**，并在这个可预测的时延下实现稳定的实时闭环。

课题骨架采用实时系统 / 嵌入式里非常正统的概念：**最坏执行时间（WCET）、资源预留（resource reservation）、端到端时序保证**。这一叙事投嵌入式 / 实时系统期刊（JSA、JRTIP、TECS 等）天然对口，三 / 四区稳，且 AAC/DVAC 那批 ML 工作根本不做时序上界，不会撞车。

## 二、模型定位与选型（VLA 是可替换负载）

**核心原则：模型是"可替换负载"，不是研究对象。** 不重新设计模型、不改 Transformer 骨干，只做理解、适配、微调、部署、测量。课题内核是"确定性推理 + 时延预算调度"，策略模型只是被部署在边缘的新负载；若某个模型踩坑，换一个负载，实时调度框架照样成立。

- **主负载：SmolVLA（450M）**——SmolVLM-2 视觉语言骨干 + 约 100M 的 flow-matching 动作专家，Orin Nano 8GB 可跑，LeRobot 原生支持。
- **备选：ACT（或更小的 MLP 动作策略）**——当 SmolVLA 出现以下任一情况时切换：部署卡壳 / 时延 P99 压不到可接受范围、50–100 条数据微调后静态成功率 <70%、任务无需语言条件。切换后后续技术栈完全不变，只换策略接口。
- **硬 Gate**：跑通 + 时延不灾难，若卡壳 >2 周即切换负载，不恋战。

## 三、课题骨架（B 方向完整论证）

以"确定性推理 / 时延预算"为论文骨架，把自适应 chunk 和事件触发作为"时延预算调度"框架下的两个具体策略。

1. **一条主线**——平台、部署、调度全是"让时延可预测、并在可预测时延下控制"这一条线上的环节；
2. **两个策略**——自适应 chunk（把 chunk 从超参数变成运行时变量）与事件触发（状态偏差超阈值即打断重推理、MCU 兜底），它们不再是"拍脑袋的工程技巧"，而是有时延预算与误差界背书的调度策略；
3. **三类贡献**——确定性部署（WCET/资源预留）、时延/抖动实测基准、时延预算驱动的闭环调度 + 误差有界分析。

一句话：做的是"让 VLA 在边缘确定性地实时跑起来，并在时延预算下闭环控制"，自适应 chunk + 事件触发装在这个框架里。
